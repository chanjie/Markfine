# Markfine

一款小巧、流畅的 macOS Markdown 编辑器，为专注写作与沉浸阅读而设计。

## 设计理念

- **编辑时，专注输入。** 以所见即所得和键盘操作为核心，让用户在排版中直接写作，手不离开键盘就能完成几乎所有写作操作。
- **阅读时，沉浸内容。** 收起编辑控件和界面干扰，保留必要的目录与导航，提供沉浸式阅读体验。

## 体验特点

### 小巧的原生客户端

基于 macOS 原生框架与系统 WebKit 构建，不附带独立浏览器运行时。安装包小巧，无需额外安装开发环境即可运行，同时支持 Intel 和 Apple Silicon。

### 流畅的本地体验

注重启动速度、输入响应和平滑滚动。正文编辑、Markdown 排版和 Mermaid 图表渲染均在本机完成，无需等待远程服务。

### 段落专注与平滑定位

当前编辑段落保持清晰，其余内容淡化。随着编辑位置变化，活动段落平滑定位到视区中部；手动滚动浏览时保持用户选择的位置。

### 在排版中直接写作

编辑标题时保留标题字号，编辑表格时仍在单元格内输入。链接平时只显示标题，光标进入时展开完整语法，离开后恢复。

需要直接操作 Markdown 标记时，可随时切换源码模式，继续使用同一份正文、选区和撤销历史。

### 随时进入阅读

阅读模式自动收起标签和编辑控件，保留文档目录与缩放入口。方向键根据段落、列表、代码和表格等内容结构滚动，退出阅读后继续原来的编辑。

关闭文档后再次打开，可选择返回上次编辑或阅读的位置。

### 从目录操作整章

在目录中直接复制、剪切或删除整章，自动包含子章节。剪切和删除支持撤销。

复制内容可携带格式和本地图片，粘贴到另一篇 Markfine 文档时，图片会迁移到目标文档的附件目录。

### 图表边改边看

编辑 Mermaid 时，上方修改源码，下方保留图表；源码有误时保留上次有效图并显示提示。

图表可放大查看、独立缩放和拖动浏览，不改变正文缩放比例。支持流程图、时序图、类图、状态图、ER 图和甘特图，全部离线生成。

### 为写作和阅读分别设置外观

提供带静态纸面纹理的纸质、牛皮纸主题，以及护眼主题和深色外观。

编辑与阅读可分别设置主题、行距和缩放比例，中英文字体也可单独选择。

## 隐私与本地处理

### 默认本地运行

正文编辑、Markdown 排版、图表生成和文档导出均在本机完成，不依赖云端服务。文档保存在用户选择的位置，由用户自行管理。

### 不做后台上报

不内置遥测、用户行为统计或云端同步，不向开发者上传文档、使用记录或诊断日志。

设置和诊断日志保存在本机。诊断日志不记录文档正文、文件路径、链接或凭据。

### 限制外部资源访问

不自动加载文档中的普通远程图片、脚本和字体。用户主动打开的网址交由系统浏览器处理。

### 图片存储由用户决定

默认将图片保存在本地。只有用户主动配置 S3 兼容存储后，才会访问指定服务上传、读取图片。

S3 访问凭据保存在系统钥匙串中，不提供给网页编辑层。除这项明确配置的图片传输外，客户端不主动调用外部网络接口。

## 平台与当前状态

支持 macOS，提供 Intel 与 Apple Silicon 通用客户端。

当前为试用版本。客户端尚未公证，首次运行可能需要在确认来源后，按照 macOS 提示批准。
