# Markfine 使用说明

## 开始使用

本地交付统一放在项目 `release/<版本号>/Markfine.app`，直接拖入应用程序目录即可；历次变更见 `release/CHANGELOG.md`，最新交付在最上方。`Dist/` 仅保留构建归档，无需从中寻找安装包。

1. 解压对应版本的 ZIP，将 `Markfine.app` 放到你有权限的位置（也可以拖到 `~/Applications`），然后双击打开。不需要 Node、npm 或 Swift。
2. 若 macOS 阻止打开，在确认包来自可信来源后，按“系统设置 → 隐私与安全性”中的提示批准。当前为 ad-hoc 内部构建，没有 Developer ID/公证；受管理设备可能需要管理员批准。不要全局关闭 Gatekeeper。
3. 默认不修改 `.md` 文件关联；用应用内“打开…”或系统“打开方式”选择 Markfine。

## 文档与编辑

- `⌘N` / `⌘T` 新建标签，`⌘O` 打开文件，`⌘S` 保存。新文档第一次保存选择名称和位置，已有文件保存回原位置。
- Markdown 源文是普通 UTF-8 文件。没有另存为、应用内重命名、自动保存、未保存内容恢复、账号或云同步。
- 点击标签切换；`⌃Tab` / `⇧⌃Tab` 切换前后标签。同名文件显示父目录帮助区分，重复打开同一文件激活已有标签。
- 新建、打开、保存位于 macOS“文件”菜单，窗体不重复展示这些按钮。双击标签栏空白处也可新建。
- 正文居中并自适应换行；标题和段落在排版中直接编辑，表格保持表格样式，可在单元格中输入，Tab／⇧Tab 切换单元格、Return 移动到下一行同列。修改仍为可撤销的 Markdown 编辑。
- 默认突出整个活动段落、弱化其余段落；不会因为光标进入标题就缩小字号。中文组词期间不强制切换标签或抢占组词按键。
- 左侧目录按 H1–H6 组织，点击标题跳转，点击箭头折叠分支；顶部目录按钮或“显示 → 显示／隐藏目录”（⇧⌘L）隐藏整个目录。
- 编辑时已有内容后的段落平滑定位到可视区纵向中线，首块内容自然顶排；目录单击跳转与定位使用140–700ms距离自适应减速动画。普通滚轮浏览不强制拉回，拖选／组词期间不抢滚动；尊重系统“减少动态效果”。
- `⌘,` 或“Markfine → 首选项…”配置界面语言（系统／中／英）、时间显示（本地／UTC）、中英文字体（默认均为苹方）、编辑／阅读主题（纸质／牛皮纸／护眼）、行号、段落专注及快捷键提示。全部属于当前 macOS 用户，不跟随文档，也不跨系统用户共享。
- 链接平时只显示标题，光标进入链接后才平滑展开整段语法。`⌘`＋左键打开：网址使用默认浏览器；文件按当前 Markdown 所在目录解析后使用系统默认程序。未保存文档无法解析相对文件路径；可执行文件、脚本和不安全协议拒绝打开。
- 表格内右键可在上下插行、左右插列，支持插一行列或输入数量批量插入（1–100），以及删行、删列、删表。光标在表格中时，右上外侧也有删除按钮；修改都可以撤销。
- `⌘Z` 撤销，`⇧⌘Z` 重做。查找为 `⌘F`，显示替换为 `⌥⌘F`；`⌘G` / `⇧⌘G` 跳转匹配，Esc 关闭查找框。替换可撤销。
- 常用样式可从“格式”菜单执行；完整键位见 [SHORTCUTS.md](SHORTCUTS.md)。

## 沉浸阅读与外观

- 点击页面“阅读”或按 `⇧⌘R`，完整渲染当前 Markdown；没有段落输入光标，不会改动正文和历史。阅读默认关闭。按 Esc／⇧⌘R，或点击顶端文档标题返回编辑。
- 阅读隐藏标签、文件树、编辑统计和窗口控件，保留目录、标题、明确的“返回编辑”和右下缩放入口；不再主动隐藏系统 Dock／菜单栏，也不突然改变窗口大小。必要的错误提示仍保留。
- 上下方向键按内容结构平滑滚动，而不是固定跳一行；左右键优先横向浏览可见的宽代码／表格，否则按页前后移动。Page Up/Down、Home/End 也可使用。
- 拖动目录右边缘改变宽度（180–360，默认220），按用户记忆。分隔条也支持键盘左右调整。展开收起有朝目录按钮方向的动画引导，分支箭头与标题对齐。
- 所有内容滚动条只在滚动时出现，静止后自动隐藏。
- `⌘+`／`⌘−`、`⌘`＋滚轮或触控板捏合缩放正文，范围50%–200%；`⌥⌘0` 恢复100%。编辑和阅读各自保存倍率，目录／菜单大小不变，`⌘0` 仍表示普通段落。
- `⇧⌘N` 或首选项开关行号。阅读中的数字是语义块在 Markdown 里的源起始行，不是屏幕折行序号。
- UTC／本地时间选项只控制保存完成时间的显示，不改写已有文本或自动插入时间。
- “帮助 → 快捷键说明”提供中英文键位清单。

## 文件夹与预览标签

- `⌘O`／“文件 → 打开…”也可选择文件夹。左侧按层显示子目录与 Markdown，可勾选“显示全部文件”；打开另一个文件夹仅替换文件树，不关闭文档。
- 文件树单击 Markdown 是斜体临时标签。当前页仍为未修改的临时页时，新文件替换它；当前页已固定则新开标签。双击文件／标签名称、实际编辑或进入阅读即可固定。打开失败、未保存或正在处理的文档不会被直接丢弃。
- 非支持格式只显示说明和默认程序按钮，始终是临时标签；脚本／可执行程序等危险目标不直接运行。
- “文件 → 打开最近”保留最近20个文件或文件夹，可清空。记录仅在本机，不自动恢复会话。
- 标题目录与文件树独立，点击目录栏“⇄”或首选项可把文档目录移到右侧，应用记忆位置；文件树仍在左侧。

## 源码、代码与图表

- 页面“源码”或 `⌘/` 在排版编辑和可编辑 Markdown 源码之间切换。正文、选区和撤销历史不另建副本；源代码模式同样遵循专注开关，默认开启。
- 常见脚本／编程语言代码块离线高亮。未知语言保持原文，不执行代码或联网下载解析器。
- 排版编辑中点击 Mermaid 会显示上方源码，下方仍保留图；输入时去抖更新，错误时保留上次有效图。默认图中文字增大，宽图可横向滚动。
- 图表“放大查看”提供独立缩放、适应窗口和拖动平移。`+`／`−`、辅助滚轮／捏合可缩放；关闭图表层不关闭文档。
- 右下缩放百分比可直接选择预设倍率。字符数与行数改在左下，行号贴近内容且颜色更淡。
- 首选项字体栏可输入关键字筛选本机字体。“恢复出厂设置…”只重置偏好，不关闭文档、不丢未保存内容、不删附件，也不清最近记录。首选项当前激活时 `⌘W` 先关闭它。
- 通过文档冷启动应用时窗口占满屏幕可用区域；这不是切换到 macOS 原生全屏 Space，阅读也不会自行收起系统界面。

## 保存与关闭

- 标签小圆点表示有未保存内容。保存过程中可以继续输入；本次保存只确认发起时的快照，后续编辑仍显示未保存。
- `⌘W` 关闭当前标签；所有标签关闭后再次按 `⌘W`，关闭主窗口并退出进程。`⇧⌘W` 关闭窗口，`⌘Q` 退出；有未保存编辑时选择保存、不保存或取消。
- 无文档启动或关完标签时，空白页展示快捷提示和随机暖心短句，不自动创建文档，也不联网获取内容。
- 保存被取消、失败，或保存期间又产生新修改时，不会直接关闭文档。
- 如果原文件被外部修改、删除或移走，应用停止保存并保留当前编辑，不自动覆盖、合并或重载。此时不要强制关闭；可复制需要保留的文本到新标签，并按需要核对磁盘文件。
- “保存结果未确认”不同于失败或取消：不要强行关闭，也不要假定原文件未写入；保留编辑并核对文件。

## 图片

- `⌘V` 优先粘贴可用的 PNG，其次 JPEG，最后 TIFF；PNG/JPEG 保留原字节，TIFF 转 PNG，不主动缩放。没有受支持图片时插入纯文本，不解析网页/Word 的 HTML、RTF 或下载远程图片。
- 未保存文档的图片先写入应用自身暂存，正文出现 `markfine-staging/…` 引用；首次保存后改为 `<文档名>.assets/…` 相对路径。
- 已保存文档粘贴图片时立即写入同级 `.assets`，但正文仍须 `⌘S` 保存。图片命名为 `image-<UUID>.png/jpg`，不覆盖原有资源。
- 处理期间有取消按钮，只锁定目标文档的编辑、保存与关闭；仍可切换并编辑其他标签。一次只处理一个图片任务。
- 撤销或删除引用不会自动删除正式 `.assets` 文件。存活标签的暂存也保留，以便撤销/重做；标签确实关闭后才清理自身暂存。
- 移动文档时把 Markdown 和同级 `.assets` 目录一起移动。远程图片不自动加载；本地图片只能读取当前文档目录/子目录与该文档自身暂存，不能通过 `../` 越界。

## Mermaid 与安全

使用 `mermaid` 围栏代码块，支持固定标准版 Mermaid 12.3.0 的流程、时序、类、状态、ER、甘特六类图表；运行时随包提供，不需要联网。

图表配置覆盖、脚本回调及主动内容被拒绝；错误保留源码和提示，不影响继续编辑。远程图像形状不会联网获取，额外图标包不从网络下载。Markdown 原始 HTML/脚本按源码显示，不执行。用户主动 `⌘`＋点击 HTTP(S) 外链才交给系统浏览器。

## 更新与已知验收边界

更新前先等待或取消图片任务，保存需要保留的文档并退出，再替换 `.app`。保留旧 ZIP 可手动回退；不要删除自己的 Markdown 或 `.assets`。

这是内部试用应用，构建标识和包校验值随包提供。构建或资源/签名核对不等于真实输入法、物理鼠标、Gatekeeper、启动/滚动/内存/热性能全部验收。首轮使用重要文档前建议保留副本。开发和构建方式见 [公共开发说明](DEVELOPMENT.md)。
