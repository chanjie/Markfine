# Markfine 使用说明

## 安装与更新

Markfine 用于在 macOS 上编辑和阅读本地 Markdown、纯文本与代码文件。通用安装包同时包含 Intel 和 Apple Silicon 版本，macOS 兼容信息见随包的 `RELEASE.md`。

1. 解压安装包，将 `Markfine.app` 拖入“应用程序”或其他有权限的位置，然后双击打开。
2. 首次打开若出现 macOS 安全提示，请确认应用来源，再按照“系统设置 → 隐私与安全性”中的提示批准。受管理的设备可能需要管理员协助。
3. 在应用中选择“文件 → 打开…”，或通过 Finder 的“打开方式”选择 Markfine。

更新前请保存文档并退出应用，然后替换 `Markfine.app`。可以保留旧安装包，便于需要时使用。

## 新建、打开与保存

- `⌘N`／`⌘T` 新建文档，双击标签栏空白处也可新建。
- `⌘O` 打开文件或文件夹。“文件 → 打开最近”和主页提供最近位置，默认记录 20 条，可在“首选项 → 编辑与导航”调整为 0–1000 条，输入后按回车确认；设为 0 会清空记录并停止新增。从文件夹导航打开的文件默认隐藏，可勾选“显示从文件夹导航打开的文件”。
- `⌘S` 手动保存。新文档首次保存为 UTF-8 Markdown，选择名称和位置；已有文档保存到原位置，保留原编码、BOM、换行和文件权限。
- 标签上的圆点表示有未保存的修改。保存期间可以继续编辑，后续修改在下一次保存时写入文件。
- 关闭有未保存修改的文档时，可选择保存、不保存或取消。取消或保存失败后，当前编辑内容继续保留。
- 如果磁盘文件已被其他应用修改、删除或移动，Markfine 会提示并保留当前编辑。请核对磁盘文件；需要保留当前内容时，可复制到新文档保存。
- 出现“保存结果未确认”时，请保持文档打开，核对磁盘文件后再处理。

## 标签与文档导航

点击标签切换文档，也可用 `⌃Tab`／`⇧⌃Tab` 切换到下一个／上一个标签。再次打开同一文件会激活已有标签，保留编辑内容和撤销历史。

点击顶部“主页”回到欢迎页和最近记录，不关闭文件夹或文档；点击文档标签可继续编辑。主页的“整理”支持选择多条记录并移除，也可移除单条或清空全部记录，包括当前隐藏的文件夹导航记录；这些操作不会删除文件。调低记录上限会移除较早的超额记录；升级时两类已有记录合计超过默认上限的部分也会移除。

如回退到 0.10.7 或更早版本，旧版不识别新的记录上限，即使新版设为 0，旧版仍可能继续记录，并按旧规则裁减历史。已经移除的记录不会因回退而恢复，文档和附件不受影响。

同名文件的标签显示用于区分的目录名，鼠标悬停可查看完整路径。活动或悬停标签的文字过长时会横向滚动，显示到右侧文件名后停留约3秒，关闭按钮保持固定。系统开启“减少动态效果”时静态显示文件名端。右键点击标签，可关闭当前标签、左侧全部、右侧全部或所有标签。遇到未保存修改时，应用会询问保存方式；选择取消将停止后续关闭。

文档目录按标题层级显示。点击标题跳转到章节，点击箭头折叠分支。顶部“目录”按钮或 `⇧⌘L` 可展开或收起目录。

右键点击目录标题，可复制、剪切或删除整章，范围包含该标题及全部子章节，至下一个同级或更高级标题前结束。剪切和删除均可用 `⌘Z` 撤销；阅读模式提供章节复制。

按住 `⌘` 单击正文链接：

- 本地 Markdown 在应用内打开或激活，保留当前编辑、源码或阅读模式。
- 带章节地址的链接定位到对应标题。跨文档时显示短暂切换动画，同文档中使用平滑滚动。
- 常见纯文本和代码链接在应用内打开原文；网址交由默认浏览器打开，其他受支持的本地文件交由系统默认应用打开。

跨文档章节链接的写法为 `[链接文字](文件.md#章节标识)`，同文档使用 `[链接文字](#章节标识)`。章节标识根据标题文字生成：英文转为小写，空格转为连字符，保留文字、数字、下划线和连字符，移除其他标点。中文可直接填写，也支持百分号编码；重复标题使用 `-1`、`-2` 等后缀区分。

相对文件地址以当前文档所在文件夹为起点，使用前请先保存文档。未找到文件或章节时，应用会显示提示。

## 排版编辑与源码模式

排版编辑中，标题、列表、链接和表格按相应样式显示，可直接修改文字。标题左上方的 H1–H6 标记表示级别。正文自动换行，编辑当前段落时会平滑调整位置，便于继续输入；首段从页面顶部开始显示。

点击“源码”、选择“显示 → 源码模式”或按 `⌘/`，可查看和编辑完整 Markdown 语法。再次切换返回排版编辑。两种模式共用正文、选区和撤销历史。

- 常用格式通过“格式”菜单或快捷键设置，完整键位见 [快捷键说明](SHORTCUTS.md)。
- 手写Markdown时保留输入的换行；格式菜单、快捷键和斜杠插入会按需补入分隔。
- 行首输入1–6个`#`并加空格可创建标题；光标处于标题标记时，淡色标记便于调整级别。格式插入后可直接继续输入，表格从首个表头开始填写，链接与图片引用可直接填写目标地址。
- 普通正文中按Tab在光标处插入缩进；列表中按Tab／⇧Tab增加／减少当前项层级，并保留续行及子项。
- 链接平时显示标题，光标进入后展开完整语法，便于修改地址。
- 表格中使用 Tab／⇧Tab 切换单元格，Return 移动到下一行同列。右键菜单提供插入、删除行列及删除整表，可批量插入 1–100 行或列。
- 逐行输入表格语法，语法成立时即显示网格，可继续填写；无需保存或移开光标。Tab／⇧Tab切换单元格，右键管理行列。
- `⇧⌘K` 删除 Markdown 源文件中的当前行，`⌥⇧⌘K` 删除当前段落。整段删除会保留代码块和表格结构。排版编辑的表格单元格中，这两个操作清空当前单元格。
- `⌘Z` 撤销，`⇧⌘Z` 重做。
- `<!-- … -->` 注释在编辑时以灰绿色等宽文字显示，阅读、导出和打印时隐藏。行内代码和代码块里的注释示例正常显示。

### 快速插入格式

在排版编辑的普通空行行首输入 `/`，可打开常用格式清单。空行提示使用淡色斜体，清单右侧显示对应快捷键。清单跟随光标，使用上下方向键选择，Return 插入，Esc 关闭，也可用鼠标点击。选择后替换 `/`，格式插入可一次撤销。源码、代码块和表格内保持原有输入方式。

输入中英文括号、引号和书名号等成对标点时，默认补齐另一半；选中文字后输入左符号可包围文字。已有右符号时跳过，空符号对可一起删除。Markdown反引号按实际输入保留，用于行内代码和围栏代码块。中文组词、粘贴和英文缩写保持正常输入。

### 有序列表编号

插入或删除列表项后，后续同级编号自动调整，保留该组的起始编号；嵌套列表各层分别编号。在列表之后、仅隔空行的位置通过 `/` 插入有序列表，会接续前一列表。

右键点击序号，可选择“重新编号”，将当前整组同级列表从 1 排起；或选择“继续编号”，接续前一组同级有序列表。没有可接续的列表时，该选项不可用。编号保存在 Markdown 中，可与编辑操作一起撤销和重做。

### 复制与粘贴

正文中 `⌘C` 复制所选文字；没有选区时复制当前整个段落，光标、选区和滚动位置保持不变。复制成功后短暂显示“已复制”；无选区复制的可见文字会短暂高亮后淡出，便于确认范围。Markdown段落副本同时保留 Markdown 与富文本，可粘贴回 Markfine，也可带格式粘贴到 Word 等应用。目标应用按其支持的格式读取内容。

排版表格中，单元格内没有文字选区时，`⌘C` 复制当前单元格可见文字；有文字选区时复制选中文字。源码模式无选区时复制整表。跨单元格拖动，或先点击起始单元格、再 Shift 点击结束单元格，可选择矩形区域并复制。右键“复制表格源码”复制整个表格的 Markdown；矩形选区粘贴到正文时保留数据行及列对齐。

跨文档粘贴 Markfine 自身复制的内容时，本地图片会复制到目标文档的附件目录；S3 图片保留原有链接。在现有表格单元格中粘贴按单行单元格文本处理，粘贴到正文可保留表格结构。

### 专注模式

专注模式突出当前编辑的内容，并淡化周围内容。普通正文按实际换行分隔，自动折行仍属于同一段；列表突出当前项，代码块与表格保持整体清晰。默认开启，适用于排版编辑和源码模式。通过“显示 → 专注模式”或首选项调整；关闭后全部内容恢复清晰。

### 查找与替换

`⌘F` 打开查找，`⌘G`／`⇧⌘G` 跳转到下一个／上一个匹配。匹配文字以黄色标记，定位后短暂闪烁；系统开启“减少动态效果”时使用静态强调。Esc 关闭查找。

点击查找面板中的“查找 ⇄”切换到替换，可替换当前匹配或全部匹配，替换操作支持撤销。阅读模式提供查找，返回编辑后可使用替换。

## 阅读模式

点击“阅读”或按 `⇧⌘R`，以只读方式浏览当前内容，包括尚未保存的修改。点击“返回编辑”、顶端文档标题，或按 Esc／`⇧⌘R` 返回编辑。查找打开时，Esc 先关闭查找。

- 标签栏自动收起，鼠标移到正文顶部可显示；切换 Markdown 标签后继续阅读。
- 点击目录标题可跳转到章节。上下方向键按内容结构滚动；左右方向键优先横向浏览宽代码或表格，其余情况下按页浏览。Page Up/Down、Home/End 同样可用。
- 文档标题、目录和右下角缩放入口保持可用。窗口标题栏的拖动、双击行为遵循 macOS 设置。
- 普通段落之间与段内换行使用相同的正文行距；标题、列表等结构保留各自的间隔。
- 关闭文档后再次打开，会从首行显示。右上角短暂提供“继续上次阅读”或返回上次编辑行的入口，点击可恢复位置。

## 文件夹导航

`⌘O` 也可选择文件夹。文件导航按层显示子文件夹与 Markdown 文件，勾选“显示全部文件”可查看其他类型。打开另一个文件夹会更新文件导航，已打开文档保持打开。

- 单击 Markdown 或纯文本文件可临时预览，标签名称显示为斜体。当前临时文档已修改时会保留；可以继续预览其他文件。
- 双击文件名或标签名、开始编辑或进入阅读，可固定标签。未修改的临时标签可以由下一次预览替换。
- 无法识别为纯文本的其他文件显示名称和“使用系统默认程序打开”按钮；不直接运行可执行文件或脚本。
- 鼠标移入文件导航后显示修改时间，离开约 3 秒后隐藏。
- 顶部“文件”按钮或面板中的收起按钮控制文件导航。目录与文件导航可分别放在左右两侧，同侧时上下排列。
- 拖动侧栏靠近正文的边缘可调整宽度，范围为 180–360；左右侧分别记忆。阅读时文件导航暂时隐藏，返回编辑后恢复。

## 纯文本与代码

文本、日志、配置、代码及其他扩展名的纯文本文件可直接编辑。点击“阅读”可只读查看原文；常见代码语言提供离线高亮。HTML、SVG和脚本也只显示原始文本，不执行代码、不预览网页、不加载引用资源。纯文本文件仅粘贴文本，不插入图片或上传附件。

支持UTF-8（可带BOM）及带BOM的UTF-16/32大小端编码。无法无损识别的编码会提示，原文件保持不变。打开和保存上限为16MiB；超限时保留当前编辑，不截断文件。

## 外观与显示设置

按 `⌘,` 打开首选项。设置保存在当前 macOS 用户账户下，对所有文档生效。

设置分为“通用”“编辑与导航”“外观”“图片与存储”四组。外观与编辑选项即时生效；S3 表单填写完成后通过“保存并使用 S3”启用。

- **语言**：跟随系统、简体中文或 English。
- **字体**：分别选择中文和英文字体，可输入名称筛选本机字体；代码使用等宽字体。
- **界面外观**：跟随系统、浅色或深色。浅色可选纸质、牛皮纸或护眼背景，编辑与阅读分别设置。欢迎页共用同一纸面；纸质和牛皮纸的背景延伸至原生窗口标题栏，深色和护眼不显示纸纹。
- **行距**：编辑与阅读分别提供紧凑、默认、宽松及自定义选项；源码模式使用编辑行距。自定义范围为紧凑行距的 0.75–2.5 倍。
- **行号**：通过首选项或 `⇧⌘N` 开关。编辑与源码显示 Markdown 源行号，阅读显示各内容块的起始源行号。
- **时间**：本地或 UTC，控制保存时间提示和文件修改时间的显示。
- **快捷键提示**：显示当前内容可用的格式快捷键。

正文缩放可使用 `⌘+`／`⌘−`、`⌘`＋滚轮、触控板捏合或右下角百分比菜单，范围为 50%–200%。`⌥⌘0` 恢复 100%。编辑与阅读分别记忆缩放比例。

“恢复默认设置…”可重置上述偏好并清除记住的 PDF／Word 导出配置；最近记录上限恢复为 20 条，超出的较早记录会移除，当前文档和附件继续保留。

### Finder 快速查看

在 Finder 中选中 `.md` 或 `.markdown` 文件并按空格，可使用 Markfine 的快速查看扩展查看排版后的 Markdown。扩展离线运行；Mermaid 图表显示源码，本地图片仅在系统允许访问时显示，否则显示占位。远程图片不会自动加载。

macOS 负责选择和启用快速查看扩展；如果显示的是原文或其他应用的预览，请检查系统设置中的“快速查看”扩展以及其他 Markdown 预览扩展。Markfine 不自动更改默认打开方式或系统扩展设置。

## 图片与图表

`⌘V` 可粘贴文本或图片，也可粘贴从访达复制的单个 PNG、JPEG 或 TIFF 图片文件。图片优先采用 PNG，其次 JPEG，TIFF 会转换为 PNG。PNG/JPEG 保留原图数据。来自 Markfine 的结构化副本按原有 Markdown 内容还原，其他外部粘贴内容按纯文本处理。

默认使用本地存储。新文档中的图片先临时保存在本机，首次保存文档时迁移到同级 `<文档名>.assets` 文件夹。已有文档粘贴图片时直接写入该文件夹，正文仍需按 `⌘S` 保存。移动文档时请一并移动对应的 `<文档名>.assets` 文件夹。

图片处理中可取消，也可切换并编辑其他文档。撤销图片插入或删除图片引用后，正式附件继续保留，便于撤销、重做及复用。

### 图片显示比例

图片默认自动适应正文：小图保持原始尺寸，大图等比缩小到正文可用宽度。右键图片或点击图片上的比例按钮，可选择相对原图的25%、50%、75%、100%、150%、200%或自定义值。超过正文宽度的选项会禁用，自定义输入会显示当前最大比例。

手动尺寸随 Markdown 保存，采用 Obsidian 图片宽度写法 `![图片|600](image.png)`，数字表示像素宽度，高度按原图比例计算。选择“自动适应正文”恢复自动显示。调整窗口、侧栏或正文缩放时，图片继续受正文宽度约束，文件内容保持不变。原图文件保留原始数据。

### S3 图片存储

在“首选项 → 图片与存储”选择 S3，填写服务的 HTTPS 地址、区域、存储桶和图片目录，再填写访问凭据。地址形式和图片访问方式应与存储服务配置一致；公开访问可填写对应存储桶根目录的图片访问地址。应用保持存储服务原有权限。

“保存并使用 S3”进行本地校验并将凭据存入系统钥匙串，成功后用于新粘贴的图片。凭据已保存时，可留空继续使用；更改服务地址、区域、存储桶、图片目录或地址形式需要重新填写。macOS 在需要时显示钥匙串授权提示。删除凭据使用该分组的独立入口。

选择“使用凭据读取”时，图片由 Markfine 使用保存的凭据读取；选择“公开链接访问”时，图片读取使用公开地址。凭据保留在原生层，公开图片请求不附带 S3 认证。保存配置不会自动测试连接。

粘贴图片后显示处理进度，成功后插入图片链接。上传失败时保留待处理图片，可修改配置后重试、改为本地或取消。已配置服务中的文档图片通过该服务读取，其他普通远程图片保留链接占位。更改粘贴位置只影响后续新图片；恢复默认设置会切回本地，保留 S3 凭据供单独管理。

Mermaid 代码块支持流程图、时序图、类图、状态图、ER 图和甘特图，图表在本机生成。排版编辑中点击图表，可在上方修改源码，下方查看图表；语法错误时保留上次有效图并显示提示。

点击“放大查看”可独立缩放、适应窗口或拖动浏览图表，支持 `+`／`−`、辅助滚轮和触控板捏合。关闭图表查看窗口后继续编辑文档。

## 导出与打印

“文件 → 导出…”或 `⇧⌘E` 可导出 PDF 或 Word（DOCX）。在保存面板中选择格式、名称、位置及排版参数。

- 默认 A4 纵向、白底、正文 12 磅，普通段落首行缩进 2 字符。
- 尚未自定义时，行距默认跟随首选项的**阅读行间距**，中英文字体默认跟随首选项；与当前处于编辑还是阅读模式无关。行距数字与阅读设置一样，都是相对阅读紧凑行距的倍数。首行缩进范围为 0–10 字符；导出行距可在约 0.2703–2.7027 倍紧凑行距之间调整，对应正文行高约为字号的 0.5–5 倍。
- PDF 和 Word 分别记忆排版配置。调整某种格式并成功导出后，下次选择该格式会使用上次的行距、字体和首行缩进；未自定义的格式继续跟随首选项。默认格式为上次成功导出的格式。取消或导出失败不保存本次更改。
- 点击“恢复跟随首选项”可恢复当前格式的默认排版；成功导出后，后续导出继续跟随首选项。恢复默认设置或在缓存清理中清理配置会清除两种格式的记忆。
- 标题、列表、代码和表格使用各自排版；代码保留等宽字体。Word 中的文字、标题、列表、表格和代码可编辑，图片与 Mermaid 图表以图片嵌入。
- Word 正文使用按所选行距换算的最小行高；较高字形或行内图片可自动撑开行框，避免内容被裁切。
- PDF 包含按标题层级组织、可跳转的书签；Word 标题保留导航层级，不额外插入目录页。独占一行的图片作为居中块输出，不套首行缩进；与文字同一行的图片维持行内排版。
- 输出使用文档内容及所选排版，纸张主题、应用界面目录、行号和界面控件留在应用中。
- 导出成功后，应用内提示约 5 秒自动消失，也可提前关闭；失败提示继续保留。允许系统通知时也会发送本地通知；点击成功通知可在 Finder 中显示导出文件。通知画面仅显示结果和文件名，系统通知的本地数据包含文件位置以便定位；权限可在 macOS 系统设置中调整。

“文件 → 打印…”或 `⌘P` 打开系统打印面板。打印继续使用当前编辑／源码／阅读模式的默认行高与首选项字体，不使用已记忆的导出配置。请等待输出完成后再关闭应用。

## 隐私与应用数据

编辑、图表生成和文档输出在本机处理，文档由你选择的位置保存。配置 S3 后，图片传输使用指定的存储服务。网址在主动打开后交给系统浏览器，其他远程图片保留链接；Markdown 中的原始 HTML 按源码显示。

错误日志保存在 `~/Library/Application Support/Markfine/Runtime/Logs/`，仅记录运行事件、时间、应用版本和错误类型等诊断信息。正文、文件路径、链接和凭证保持私密。

Markfine 菜单中的“缓存清理…”可查看日志、临时文件、运行缓存、配置和记录的占用。配置与历史记录需要主动勾选并确认清除；文档和附件保留在原位置。
