# Markfine MVP 快捷键清单

- **适用范围**：macOS Apple Silicon MVP；不提供应用内快捷键自定义

`⌘ Command` · `⌥ Option` · `⌃ Control` · `⇧ Shift`。反引号指 `` ` `` 键；含 Shift 时仍按同一个物理键。

## 1. 应用、文档与标签页

| 操作 | 已确认键位 |
| --- | --- |
| 新建文档／新标签 | ⌘N／⌘T，行为相同 |
| 打开 | ⌘O |
| 保存 | ⌘S |
| 关闭标签 | ⌘W |
| 关闭窗口 | ⇧⌘W |
| 退出应用 | ⌘Q |
| 隐藏应用 | ⌘H |
| 最小化窗口 | ⌘M |
| 下一标签 | ⌃Tab |
| 上一标签 | ⇧⌃Tab |

关闭标签、窗口和退出应用均遵循 [文档保存规则](REQUIREMENTS.md)，不得因快捷键路径不同而绕过未保存确认。

新文档首次保存可选择文件名和位置；已有文档的 ⌘S 保存当前文件。不提供另存为及 ⇧⌘S 动作。

## 2. 基本编辑

| 操作 | 已确认键位 |
| --- | --- |
| 撤销 | ⌘Z |
| 重做 | ⇧⌘Z |
| 剪切 | ⌘X |
| 复制 | ⌘C |
| 粘贴 | ⌘V |
| 全选 | ⌘A |

正文中的文本粘贴仍按纯文本处理，图片粘贴仍按 MVP 的本地资源流程处理，不由本表新增格式化粘贴能力。

## 3. 当前文档查找与替换

| 操作 | 已确认键位 |
| --- | --- |
| 查找 | ⌘F |
| 显示替换 | ⌥⌘F |
| 下一匹配 | ⌘G |
| 上一匹配 | ⇧⌘G |
| 关闭查找面板 | Esc |

替换当前项和替换全部可通过 Tab 聚焦按钮、Return 执行，不另设组合键。替换可撤销，查找与替换仅作用于当前文档。

## 4. Markdown 样式与结构

| 操作 | 已确认键位 |
| --- | --- |
| 标题 1–6 | ⌘1–6 |
| 普通段落 | ⌘0 |
| 加粗 | ⌘B |
| 斜体 | ⌘I |
| 行内代码 | ⌥⌘K |
| 删除线 | ⌃⇧反引号 |
| 链接 | ⌘K |
| 图片引用 | ⌃⌘I |
| 代码块 | ⌥⌘C |
| 引用块 | ⌥⌘Q |
| 有序列表 | ⌥⌘O |
| 无序列表 | ⌥⌘U |
| 任务列表 | ⌥⌘X |
| 插入 Markdown 表格模板 | ⌥⌘T |
| 增加缩进 | ⌘] |
| 减少缩进 | ⌘[ |

图片引用动作仅插入 Markdown 引用，不新增图库管理。表格动作插入 Markdown 表格模板，不由键位确认扩展为图形化表格管理功能。

## 5. 已确认的冲突与焦点处理

1. 通用操作遵循 macOS 惯例，Markdown 业务操作尽可能参考 Typora，但不覆盖系统惯用动作：
   - 保留 ⌘H 为隐藏应用；替换使用 ⌥⌘F，不照搬 Typora 的 ⌘H。
   - 保留 ⌘反引号及 ⇧⌘反引号用于系统窗口导航；行内代码使用 ⌥⌘K，不照搬 Typora 的 ⇧⌘反引号。
2. 格式快捷键只在正文聚焦时生效；剪贴板、撤销等操作跟随当前输入控件，不应误作用于后台正文。
3. 不抢占中文输入法组词期间的 Return、Esc 和方向键；Esc 关闭查找面板不能打断输入法正在处理的组词。
4. 原生菜单和 Web 编辑器不得重复执行同一动作。
5. 菜单/键位实现与实际系统键盘布局、焦点和输入法验收分别核对，不凭文档键位表推导实机全部通过。

## 6. 验收范围（尚未执行）

- [ ] 表内各动作均可通过约定键位执行，同一事件不会因菜单与 Web 编辑器同时处理而执行两次。
- [ ] ⌘N 和 ⌘T 行为相同；标签切换及关闭动作遵循已确认的文档状态与保存规则。
- [ ] 剪贴板、撤销/重做、全选等操作跟随实际聚焦的输入控件；正文格式动作不影响查找输入框等其他控件。
- [ ] 中文输入法组词期间的 Return、Esc、方向键不被业务命令抢占。
- [ ] 查找、匹配跳转、显示替换和关闭面板可通过键盘完成；替换当前项和替换全部可通过 Tab、Return 执行，替换可撤销。
- [ ] ⌘H 仍隐藏应用；系统窗口导航组合键不被行内代码动作占用。

## 7. 范围

不新增应用内文档重命名/资源目录联动改名、图形化表格或图库管理。首次保存命名与图片迁移不受此限制。完整边界见 [产品需求](REQUIREMENTS.md)。
