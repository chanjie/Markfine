# Markfine 快捷键说明

适用于 macOS 上的 Intel 和 Apple Silicon 通用客户端。

`⌘ Command` · `⌥ Option` · `⌃ Control` · `⇧ Shift`。反引号指 `` ` `` 键；组合键含 Shift 时，仍使用同一个物理键。

## 文档与应用

| 操作 | 快捷键 |
| --- | --- |
| 新建文档／新标签 | ⌘N／⌘T |
| 打开文件或文件夹 | ⌘O |
| 保存 | ⌘S |
| 导出 PDF／Word | ⇧⌘E |
| 打印 | ⌘P |
| 关闭当前标签；无标签时关闭主窗口并退出 | ⌘W |
| 关闭窗口 | ⇧⌘W |
| 退出应用 | ⌘Q |
| 隐藏应用 | ⌘H |
| 最小化窗口 | ⌘M |
| 首选项 | ⌘, |
| 下一标签 | ⌃Tab |
| 上一标签 | ⇧⌃Tab |

新文档首次保存时选择名称和位置，已有文档保存到原位置。关闭有未保存修改的文档时，可选择保存、不保存或取消。

辅助窗口、系统面板或前层对话框打开时，`⌘W` 优先关闭或取消当前界面。

## 编辑

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | ⌘Z |
| 重做 | ⇧⌘Z |
| 剪切 | ⌘X |
| 复制 | ⌘C |
| 粘贴 | ⌘V |
| 全选 | ⌘A |
| 删除当前行 | ⇧⌘K |
| 删除当前段落 | ⌥⇧⌘K |

剪贴板与撤销操作作用于当前输入位置。`⌘V` 可粘贴纯文本或图片，图片保存方式见 [使用说明](USAGE.md#图片与图表)。

正文中 `⌘C` 复制文字或单元格选区；没有选区时复制整个段落，并保持光标与滚动位置。排版表格中，无文字选区时复制当前单元格文字；源码模式无选区时复制整表。Markdown段落可带格式粘贴到 Markfine 和 Word 等应用。目录右键提供整章复制、剪切与删除，包含子章节。

表格中可跨单元格拖动或用 Shift 点击选择矩形区域；“复制表格源码”位于右键菜单。排版编辑普通空行行首输入 `/` 打开格式清单，使用上下键选择、Return 插入、Esc 关闭。

格式清单右侧显示对应快捷键。输入中英文成对标点会默认补齐；纯文本与代码文件提供原文编辑、只读查看及常用编辑键位，不使用Markdown格式命令。

删除整行按 Markdown 源文件中的行处理；整段删除保留代码块和表格结构。排版编辑的表格单元格中，这两个操作清空当前单元格。删除操作可撤销。

中文组词期间，Return、Esc 和方向键由输入法处理。

## 查找与替换

| 操作 | 快捷键或入口 |
| --- | --- |
| 查找 | ⌘F |
| 查找／替换切换 | 点击面板中的“查找 ⇄／替换 ⇄” |
| 下一个匹配 | ⌘G |
| 上一个匹配 | ⇧⌘G |
| 关闭查找 | Esc |

查找和替换作用于当前文档。替换按钮可通过 Tab 聚焦、Return 执行，单处及全部替换均支持撤销。阅读模式提供查找，返回编辑后可使用替换。

## Markdown 格式

| 操作 | 快捷键 |
| --- | --- |
| 标题 1–6 | ⌘1–6 |
| 普通段落 | ⌘0 |
| 加粗 | ⌘B |
| 斜体 | ⌘I |
| 行内代码 | ⌥⌘K |
| 删除线 | ⌃⇧反引号 |
| 插入链接 | ⌘K |
| 打开链接 | ⌘＋鼠标左键 |
| 插入图片引用 | ⌃⌘I |
| 代码块 | ⌥⌘C |
| 引用 | ⌥⌘Q |
| 有序列表 | ⌥⌘O |
| 无序列表 | ⌥⌘U |
| 任务列表 | ⌥⌘X |
| 插入表格 | ⌥⌘T |
| 增加缩进 | ⌘] |
| 减少缩进 | ⌘[ |

格式快捷键在正文输入时生效。图片引用动作插入 Markdown 图片语法，可继续填写图片地址。

表格中，Tab／⇧Tab 切换前后单元格，Return 移动到下一行同列，Esc 返回正文。方向键可在单元格边界移动，或进入、离开表格。右键菜单提供插入及删除行列、删除整表，操作均可撤销。

## 显示与缩放

| 操作 | 快捷键 |
| --- | --- |
| 阅读／编辑模式 | ⇧⌘R |
| 源码／排版编辑 | ⌘/ |
| 显示／隐藏目录 | ⇧⌘L |
| 显示／隐藏行号 | ⇧⌘N |
| 放大／缩小内容 | ⌘= 或 ⌘+／⌘− |
| 恢复100%缩放 | ⌥⌘0 |
| 鼠标／触控板缩放 | ⌘＋滚轮／双指捏合 |

“显示 → 专注模式”或首选项可调整段落专注。编辑与阅读分别记忆缩放比例。

侧栏分隔条聚焦后，左右方向键调整宽度，Home／End 调整到最小／最大宽度。

图表放大查看中，`+`／`−`、`⌘`＋滚轮或捏合可缩放，拖动可平移，Esc 或关闭按钮返回文档。

## 阅读导航

| 操作 | 快捷键 |
| --- | --- |
| 按内容结构上下滚动 | ↑／↓ |
| 横向浏览宽代码或表格，其余情况下按页浏览 | ←／→ |
| 向前／后翻页 | Page Up／Page Down |
| 文档开头／末尾 | Home／End |
| 返回编辑 | Esc／⇧⌘R |

查找打开时，Esc 先关闭查找。点击顶端文档标题或“返回编辑”也可结束阅读。
