# Markfine 产品需求

## 1. 目标与范围

面向 macOS Intel 与 Apple Silicon 的轻量 Markdown 与纯文本客户端，优先可靠的本地文件编辑、块级实时排版和高效键盘操作。源文件是唯一持久化正文，不引入专有文档格式。

首版必须在同一应用中包含：真实文档闭环、多标签、块级 Markdown、查找替换与常用快捷键、纯文本/本地图片粘贴及首次保存迁移、离线 Mermaid。不能用单文档或仅文字版本替代。

- 当前使用对象为内部少量用户，不通过 Mac App Store 分发。
- 正式运行验收环境为 macOS 26.7.2 / Apple Silicon，性能基准为 Apple M5 / 32 GiB；其他系统未承诺兼容。工程部署目标不等同于最低支持版本。
- Typora 仅作为体验参考，独立设计实现，不复制其代码或资源。

## 2. 文档与多标签

- 新建 UTF-8 Markdown 文件；打开 Markdown 与可无损识别的纯文本文件。同窗口多标签，正文、选区、历史、滚动位置与脏状态相互独立；文本编码与大小边界见 §15。
- 同一文件只保留一个标签；重复打开激活已有标签，不重载编辑内容。同名不同文件应可区分，不能以标题关联读写。
- 显式 `⌘S` 保存。新文档首次保存选择名称和位置，已有文件保存回当前路径；不提供另存为或应用内重命名。
- 首次保存覆盖已有文件须经系统替换确认，目标已在其他标签打开时拒绝覆盖。
- 保存前检查文件身份、内容和元数据；外部改写、删除、移走或替换时停止保存并保留编辑，不自动覆盖、重载或合并。
- 写入失败保护旧文件及当前编辑；提交后结果无法确认必须区别于“未写入”，不得自动重试或关闭。
- 保存期间允许继续输入。回执仅确认对应文档/请求/版本的快照，不重载正文、选区或历史；后续编辑保持未保存，撤销回保存内容恢复干净状态。
- 同文档保存串行，重复显式保存可合并排队，不让旧快照后写覆盖新快照。
- 关闭标签、窗口、退出都处理未保存修改，提供保存、放弃或取消。取消/失败/保存后新修改应中止关闭。最终批准与真正关闭之间不得丢失新输入。
- 不做自动保存或异常退出后的未保存正文恢复。

## 3. 编辑与语法

- 正文在编辑区域水平居中，100% 缩放时列宽 480–860 CSS px，随可用宽度换行；小于最小宽度时可横向滚动。目录不计入正文列的居中区域。连续调整窗口、切换长短文档或呈现模式后仍按当前可用区域与倍率排版，不沿用旧视口的宽度；从默认窗口扩大后连续滚动也不改变列宽或缩放倍率。
- 标题和段落直接保留排版编辑，不因光标进入切换为另一套等宽源码布局；标题字号、段落行高与间距保持一致。表格在表格单元格中编辑，修改写回同一 Markdown 正文并参与同一撤销历史，不整体退回管道源码。复杂语法保留源文，不能静默丢失内容。
- 专注模式默认开启：普通正文按用户显式换行分隔聚焦，自动折行仍属于同一段；列表突出当前项及其续行，代码块与表格保留整体结构。其余内容弱化，不单独缩放活动内容。
- 编辑时，已有内容之后的活动段落以减速动画定位到正文可视区纵向中线；第一块内容自然顶排，不为居中留下半屏空白。文末留白允许后续段落居中。目录单击跳转与正文定位共用按距离计算的动画（140–700ms），不改变正文或额外改动选区，不因普通滚轮浏览、窗口调整、焦点恢复或仅切换标签而强行拉回旧光标，不在拖选／组词中途移动视口。
- 引用符号隐藏，普通无序列表显示圆点、任务显示复选框；只读文本不能用仍显示源符号代替渲染。行内链接平时仅显示标题，光标进入该链接才展开完整语法，展开时带短促排版过渡，离开后恢复。
- 快捷键提示默认开启：光标停留在支持格式快捷键的内容中时淡显实际键位，不遮挡正文或占用正文排版空间。
- 正常中文组词，不抢占输入法处理中的 Return、Esc、方向键；组词期间不强制切换标签或执行业务命令。
- 核心语法基线为 CommonMark 0.31.2；GFM 参考 0.29-gfm，仅明确加入表格、任务列表、删除线、自动链接。
- 有序列表在插入、删除列表项或移除列表标记后，按位置调整受影响列表的同级编号，保留原起始编号；删除首项仍保留该组原起始值。嵌套各层独立，编号位数变化时保持续行与子块缩进结构。编号与原操作一同写回Markdown并撤销／重做；打开文件或只修改普通文字不自动整理原编号。
- 编辑模式在有序列表序号上右键可“重新编号”或“继续编号”。重新编号将当前整组同级列表从1排起；继续编号接续同一容器内的前一组同级有序列表，没有可接续列表时禁用。作用范围按右键目标确定，不先移动光标或选区；阅读不提供修改操作。
- 原始 HTML 和脚本仅显示源码；文档注释的编辑／阅读／输出区别见 §11。安全策略导致的语法差异单独说明，不宣称完整原始 HTML 或 GitHub 网站行为兼容。
- 不支持/渲染失败保留原文并提示，但不得把全部降级视为已声明语法正确渲染。
- 当前文档查找与替换可通过键盘完成，替换可撤销；格式动作只作用于聚焦的正文，剪贴板/撤销跟随实际输入控件，菜单和编辑器不得执行两次。
- 格式命令保持原有文字光标或选区的对应位置，不把整行标记设成待替换选区；插入标题、列表、引用、代码块后可直接输入。表格插入后进入首个表头，链接与图片引用选中目标地址；格式及必要的段落分隔为一次可撤销操作。标题标记输入位置保持可见，支持连续输入1–6个`#`并加空格；既有Setext标题保持解析。手输列表标记和内容时保留原有换行，不自动补空行；未完成的标记保留为输入中的文本，完成非空列表项后按当前语法呈现。通过菜单、快捷键或斜杠调用格式命令时，模板仍可补入所需分隔。
- 正文Tab在当前光标处插入缩进；列表Tab／Shift-Tab增加／减少当前项层级并保留其续行与子项，非表格正文不进入其他表格或侧栏控件。单元格内的行内格式由当前单元格编辑器执行，写回同一正文和历史；不在单元格内执行会破坏表结构的块级格式动作。表格中的`⌘/`仍只切换源码，不插入注释。
- 逐字符构造新表格或直接续写旧表时保留当前输入位置，不能因表格被语法树识别而把后续输入移到文档其他位置。语法成立时实时显示表格网格并可继续填写，不依赖保存、移开光标、切模式或额外空行；已存在表格的直接单元格编辑不变。
- 键位基线见 [SHORTCUTS.md](SHORTCUTS.md)，不提供应用内自定义快捷键。

## 4. 剪贴板、图片和资源生命周期

- 图片数据选择顺序为可用 PNG → JPEG → TIFF。PNG/JPEG 原字节保存，TIFF 转 PNG，不主动缩放或有损再压缩，扩展名匹配实际格式。
- 支持粘贴从访达复制的单个 PNG、JPEG 或 TIFF 文件，读取文件实际图片数据而非文件图标；多文件、不可读取或不安全的文件不会插入坏图片。
- 没有可用图片则按纯文本粘贴；Markfine自身的结构化副本按 §14 还原。普通外部HTML/RTF不解析为正文或图片，不下载普通外部URL，不承诺动画粘贴保留或SVG/PDF矢量转换。
- 无受支持内容提示不支持，不插坏链接或改变正文；已有资源文件不重新编码。
- 已保存文档粘贴时立即写入同级 `<文档名>.assets/` 后插入相对引用，资源写入不等于保存正文。
- 新文档图片先写自身暂存、可预览，首次保存迁移为 `.assets` 相对路径。迁移不破坏当前编辑、选区、历史或后续修改，也不能全局替换普通文字/代码中的相似字符串。
- 文件名 `image-<UUID>.<实际扩展名>`，每次新建，不沿用剪贴板名称、不按内容去重；重名换 UUID，不覆盖、改名或删除原资源。资源目录被普通文件占用或不可写时报错，保留暂存。
- 图片处理异步，显示可取消提示；仅锁目标文档的编辑/保存/关闭/再次粘贴，允许滚动及切换、编辑其他标签。同一时刻最多一个图片任务，退出前等待或取消。
- 任务绑定文档、插入位置、版本和任务 ID。成功一次可撤销插入；失败/取消不改正文，迟到回执无效。临时提示不进入 Markdown 或历史。
- 存活标签的暂存不因删除引用、撤销或保存成功而立即清理。只有真正关闭标签后清理自身暂存；取消关闭/保存失败继续保留。
- 正常退出确认后清理本会话；异常退出后仅清理可证实已失效的会话，存活或无法确认的保留。清理限应用管理目录，失败不阻断编辑。
- 正式 `.assets` 永不自动清理，即便已无引用。保存后重新打开或 Markdown 与 `.assets` 一起移动，图片应仍有效。

## 5. 离线图表与内容安全

- 固定标准版 `mermaid@12.3.0`，首版保证流程、时序、类、状态、ER、甘特六类；不自动跟随最新版或改用 tiny 分发。
- Mermaid 运行时本地打包，不依赖 CDN/外部服务。严格安全模式，禁止脚本回调、安全配置覆盖和远程资源加载；错误保留源码与提示，不阻断编辑。
- 默认不联网加载文档的图片、脚本、字体；配置S3后的指定图片传输以 §14 为明确例外，其他远程图片继续显示占位和原链接，不改写源文。用户主动点击 HTTP(S) 外链才交系统浏览器，编辑器不得导航走应用页面或执行危险协议。
- 本地图片仅当前文档目录/子目录和该文档自身暂存；未保存文档仅自身暂存。路径规范化、符号链接及竞态不能绕过权限，不扩大到整个工作区或其他标签。
- 文档内容不拥有原生能力。桥接需校验来源、frame、独立 content world、会话、能力、文档、请求和版本；只能调用固定应用命令，不接收任意文件路径或执行系统命令。

## 6. 性能目标

下列为验收目标，不是当前全部已实测通过的结果：

| 指标 | 目标与口径 |
| --- | --- |
| 20 KiB UTF-8 文档启动 | 完全退出后打开到首屏可见且可输入 ≤1 秒，保留系统文件缓存 |
| 1 MiB 综合文档打开 | 到首屏可见、可输入且预览可用 ≤3 秒 |
| 输入到显示 | P95 ≤100 ms |
| 离开活动块到该块排版出现 | P95 ≤200 ms，不计停留编辑时间 |
| 滚动帧 | P95 ≤33 ms，无 >300 ms 明显卡顿 |
| 1 MiB 稳态内存 | 完整浏览并稳定后采样 60 秒，每次合计主程序及确认归属的 WebKit RSS，最大值 ≤300 MB |
| Release `.app` 体积 | ≤50 MB，不用 ZIP 大小代替 |

20 KiB 启动文档不含图片/图表；1 MiB 样例包含常用语法、六类小图和四张本地 PNG/JPEG，附件字节另计。两档启动各保留 10 轮、输入和预览各至少 100 次、滚动 3 轮每轮至少 30 秒。Gatekeeper 人工批准不计启动性能，启动/图片转换峰值另记，不能以均值代替稳态最大值。

常规小文档还需关注空闲及持续编辑的 CPU、内存、热压力，与同机同文档参考体验比较；数值/热判据尚未确认，不凭空作达标承诺。

## 7. 分发与非目标

- 新建、打开、保存通过 macOS 系统菜单及快捷键提供，不在正文窗体重复放置按钮。标签栏空白处双击新建空白文档。
- H1–H6 文档标题目录支持单击跳转、逐分支折叠与整体隐藏，默认在左侧，可记忆到右侧；文件夹浏览为独立文件树，可分别设置左右位置，不把标题和文件混为一棵树。
- 窗口采用连续背景和弱边界，不显示应用版本或名称装饰句点；保留原生窗口控制与缩放。版本仍保留在包元数据和“关于”信息中。
- `⌘,` 打开原生首选项。快捷键提示、段落专注默认开启；新增中英文界面、时区、中文／英文字体、分模式主题和行号设置，立即生效并按当前 macOS 用户保存，不写入 Markdown 或资源目录。
- 原创 AI 主题应用图标随包提供；图标表达视觉定位，不代表新增 AI 调用、账号、云服务或文档上传。

SwiftPM Release Universal `.app`，同时包含 arm64 与 x86_64，运行资源共用并全部随包；当前 ad-hoc 本地签名、ZIP/SHA-256 和版本说明，不要求使用者安装开发工具。无 Developer ID/公证，不关闭系统安全策略，不自动安装或改默认文件关联。更新前完成图片任务、保存并退出，只替换 `.app`，保留旧包便于手动回退，不改用户文档或 `.assets`。

当前不含：其他平台、账号/应用内同步、另存为/重命名、自动保存/恢复、普通外部HTML/RTF格式化粘贴、插件/AI、自定义快捷键、数学/脚注等额外语法、安装器和自动更新。Word/PDF导出及打印在 §10 增补，S3与应用自身结构化副本在 §14 增补。

## 8. 阅读、外观与表格增强

- 阅读模式默认关闭，不记忆为下次启动模式。页面“阅读”按钮或 `⇧⌘R` 开启，`Esc`／同一快捷键／点击阅读页文档标题返回编辑。
- 阅读使用同一 Markdown 正文的只读完整渲染，不存在活动段落或表格输入光标，不更改正文、选区、历史或未保存状态。CommonMark、既定 GFM 和离线 Mermaid 均渲染；HTML、网络图片和主动内容仍遵守原安全限制。
- 阅读模式普通段落不叠加额外的段前／段后留白，相邻段落间与段内换行使用同一正文行距，并随已有阅读行距设置与缩放变化。标题、列表、代码与表格继续保留各自结构间隔，不新增段距设置。
- 阅读标签栏动画自动收起并可在顶部悬停浮出；隐藏文件树、格式提示和统计，保留原生红黄绿窗口按钮、文档目录、文档标题、醒目的“阅读模式／返回编辑”与右下缩放入口。不主动隐藏系统 Dock／菜单栏，不自动切换原生全屏或改变用户调整的窗口大小；错误提示仍保留。
- 阅读上下方向键根据段落、标题、列表、代码、表格和图片调整滚动步长；左右键优先滚动可见的溢出代码／表格，否则按页浏览。Page Up/Down、Home/End 可用。滚动采用减速动画，连续输入接续目标，用户滚轮可中止；尊重系统“减少动态效果”。
- 文档目录与文件导航所在侧栏均支持拖动内侧边缘，默认 220、最小 180、最大 360 CSS px；键盘聚焦分隔条后可用左右键调整，Home/End 到上下限。同侧共宽、左右分别记忆。窄窗同时打开两侧导航时临时收窄导航，给正文保留至少240 CSS px可见区域；扩大窗口恢复已记忆的宽度，不因自动布局改写偏好。按钮具有明确目录图标与文字，整体收起／展开沿按钮方向动画；分支箭头与文字垂直对齐。
- 目录、正文、宽代码和表格的滚动条只在滚动时出现，停止后隐藏，不在悬停或空闲时常驻。
- 内容缩放范围 50%–200%，编辑与阅读分别记忆；支持键盘、`⌘`＋滚轮和触控板捏合，不缩放目录与菜单。恢复比例使用 `⌥⌘0`，保留 `⌘0` 的普通段落格式动作。
- 首选项界面语言支持跟随系统、简体中文、English，覆盖原生菜单、首选项、Web 界面、表格菜单及快捷键帮助。
- 时间显示可选本地（跟随系统时区）或 UTC，用于应用保存时间提示与文件导航修改时间，不转换／重写文档中的时间，也不增加时间插入操作。
- 中文、英文分别选择本机字体，默认均为苹方；按字符范围分配，避免一套字形覆盖另一项设置，不联网下载字体。代码保留等宽字体。
- 编辑与阅读主题独立选择：纸质（默认）、牛皮纸、护眼；不因切换模式覆盖另一模式的设置。
- 行号默认关闭，首选项或 `⇧⌘N` 切换。编辑行号对应 Markdown 源行；阅读显示顶层语义块的源起始行号，不伪装为视觉折行行号。
- 表格右键菜单支持在当前行上下／当前列左右插入一行列，或输入数量批量插入（1–100）；支持删除当前行、列和整表。结构变化是同一正文的一次可撤销事务；删除表头会提升下一行为表头，删除最后一列／唯一一行等价于删表。原有转义管道与列对齐保留。
- 光标在表格内时，表格右上外侧显示整表删除按钮；离开后隐藏。阅读模式无编辑菜单和删除控件。
- `⌘`＋左键点击链接：HTTP(S) 交默认浏览器，本地相对路径按当前 Markdown 所在目录解析后交默认程序；未保存文档的相对路径无默认根目录。普通点击仅用于编辑标题，不导航 WebView。危险协议、网络文件主机、可执行程序／脚本、应用包和跳转文件拒绝打开；不改变本地图片的读取权限。
- 所有标签关闭后保留空白主窗口，再次 `⌘W` 关闭主窗口并结束应用进程；已有的保存／取消保护不可绕过。直接启动且没有打开文件时不自动创建文档，空白页显示使用 tips、随机暖心短句与本地简洁风景装饰；不联网，不定时刷新打扰用户。
- “帮助 → 快捷键说明”提供简洁的中英文应用内帮助，目前只列实际可用键位。
- Markfine 自有代码与文档采用 MIT，许可证随应用提供；第三方组件保留各自许可与随包归属，不将其统一改成 MIT。

## 9. 文件夹、源码与连续交互增强

- “打开…”可选择文件或文件夹，一次只维护一个文件夹树；替换文件夹不关闭已有标签。根目录和各子目录按层枚举，不递归预扫整个磁盘。默认显示目录与 `.md`／`.markdown`（忽略大小写），可勾选并记忆“显示全部文件”。
- 文件树和文档目录分别记忆左右位置，同侧时上下分区，不同侧时独立显示。支持左右迁移的短暂飘移动画，位置按当前系统用户记忆并用于所有文档。
- 单击文件树中的 Markdown 打开斜体临时预览。当前活动标签是干净、无待处理任务的临时预览时，新文件成功打开后替换它；当前为固定标签时新开临时标签。不替换后台标签、不清掉未保存内容，失败保留旧页；连续点击仅最新请求可以激活文档。
- 双击文件名／标签名、发生实际编辑或进入阅读会固定 Markdown 标签并恢复正体。已打开的同一文件仍只激活已有标签、保留正文／历史。直接通过文件菜单／系统打开的 Markdown 默认固定。
- 无法识别为纯文本的非支持格式仍是斜体临时标签，不读成 Markdown；正文区域分行显示不支持说明和“使用系统默认程序打开”。该按钮只使用原生登记的文件 ID；危险协议、可执行程序／脚本／包仍不得直接运行。纯文本与代码文件按 §15 在应用内处理。
- 文件夹桥接仅接收会话中的目录／条目 ID 与代次，不接收任意路径；固定根目录描述符，逐层打开时禁止跟随目录符号链接，检查根身份及越界。刷新枚举使用独立读取游标，旧根／旧请求回执不得覆盖新状态。此授权不扩大文档图片的读取范围。
- 文件菜单提供“打开最近”，按实际成功打开的文件或文件夹去重，最新置顶、最多20条；本地按系统用户保存，不上传、不自动恢复或读取所有最近文档。缺失位置打开失败时保留当前文档，可清空记录。
- 排版编辑／可编辑源码／只读阅读使用同一正文、选区和撤销历史。`⌘/` 或页面按钮切换源码，原始 Markdown 标记完整可见、可编辑，不写入新的专有格式；阅读切换仍不会修改正文。
- 专注模式开关默认开启，同一开关用于排版编辑与源码，普通正文显式换行与自动折行的区别见§3；代码块与表格保持结构范围。关闭后恢复全部内容清晰，不清除正文历史。
- 常见脚本及编程语言离线高亮，固定 `highlight.js@11.12.0`，仅打包选定语言；已覆盖 JavaScript／TypeScript、Python、Shell、Swift、Go、Rust、Java、C/C++、C#、JSON、YAML、HTML/XML、CSS、SQL、Ruby、PowerShell。未知语言或超大单块保留转义原文，不执行代码、不联网获取语言。
- Mermaid 活动块上方显示可编辑源码、下方保留渲染图；编辑去抖更新，旧回执无效，新图未就绪或源码错误时保留上次有效图及错误提示。源码模式仅显示原始代码，阅读仅显示图。
- Mermaid 默认文字增至20px，内嵌宽图允许横向浏览，不把整图缩成无法阅读的小字；“放大查看”打开应用内图表层，可适应窗口、20%–500%独立缩放、拖动平移，支持键位／辅助滚轮／捏合；关闭不影响文档和内容缩放。
- 编辑、源码、阅读行号贴近内容列，使用更淡的颜色和独立留白；编辑／源码是源逻辑行，阅读是语义块起始源行，均不把折行当作新源行。
- 字体控件可输入关键字，按本机字体名称及 PostScript 名过滤选择；不接受任意未安装名称作为字体设置。首选项提供恢复默认偏好，执行前确认；仅重置偏好白名单，保留当前文件夹、标签、未保存内容、附件和最近记录。
- 缩放即时应用连续浮点增量，不在每个手势增量取整、不等待下一次鼠标点击；偏好持久化不反向覆盖正在进行的缩放。右下百分比可点击选择预设倍率，字符／行数统计移至左下；缩放和统计不是正文内容。
- 首选项为当前 key window 时，`⌘W` 优先关闭它，不向后台文档发送关闭。通过文档冷启动时主窗口占满当前屏幕可用区域（非新建全屏 Space）；用户后续调整窗口大小不被阅读切换覆盖。
- 普通编辑的方向键可从相邻段落进入表格，在单元格边界进入相邻单元格／离开表格；组词期间不接管按键。目录按钮背景与展开／收起状态一致，目录标题单击即可导航。

## 10. 运行数据、导航与文档输出

- `Markfine → 首选项…` 下方提供“缓存清理…”，不置于首选项窗口内。分类统计 App 自身日志、运行临时文件／临时依赖、可重建缓存、配置和全局记录。配置、最近位置及编辑／阅读记录默认不选，清除前明确影响并二次确认；配置只重置偏好白名单。
- 缓存功能不扫描／删除 Markdown、正式附件或文档图片暂存，不清系统统一日志和内置必需依赖。活跃会话的运行依赖受文件锁保护，清理失败或受保护项目保留，不能声称强制清空全部运行数据。
- 阅读模式标签栏带动画自动收起，顶部悬停或键盘聚焦入口可覆盖式浮出，移出后延迟收起，不挤动正文或改变窗口外框。切换其他 Markdown 标签后仍阅读并固定该标签；不支持类型不提供阅读。阅读顶部空白支持双击缩放窗口。
- 编辑时顶部居中显示文件名；标签悬停约0.5秒显示操作系统全路径。同名文件按全组一致的最近可区分层级标识：`config/review.md`，多级时只显示 `alpha/…/review.md`，不保留任何中间目录。目录名集合本身不足以区分的极端路径排列，只在差异目录上附稳定序号，保证最终标签不重名。
- 标签保持有限宽度。活动或悬停标签的文字超过可用宽度时横向往返显示，左端约停1秒，右侧文件名端约停3秒；关闭按钮与未保存标记固定。持续输入不重建未变化的标签或重启滚动。无溢出、后台与非活动且未悬停的标签不持续动画；系统减少动态效果时静态显示文件名端，完整路径提示保留。
- 标签右键以点击目标提供关闭当前、关闭左侧全部、关闭右侧全部、关闭所有；没有对应方向标签时不显示该菜单项。批量关闭沿用未保存保护，取消后停止后续关闭。
- 首次打开文档从首行开始；同一绝对路径关闭后重开仍从首行开始，右上提示5秒，可点击平滑跳转。编辑／源码关闭时记光标最后所在行，阅读关闭时记实际浏览位置（源段落和块内比例）；仅切换存活标签不重置或再提示。不持久化正文，不自动恢复会话。
- 无文档时隐藏文档目录及按钮，侧栏展示最近打开记录；点击才打开，不自动读取历史文件。已有文件夹树仍可作为浏览入口。
- 查找所有可见命中词黄色底色，跳转使命中行纵向居中，滚动完成后该行命中词高亮闪烁三次。系统减少动态效果时静态强调。关闭查找清除高亮，但仍完成本次已请求的定位及重排校正，不将页面拉回旧位置。`⌘F` 默认查找，点击“查找 ⇄／替换 ⇄”切换；替换无独立快捷键，支持单处和全部替换且可撤销。阅读只可查找，Esc 优先关闭查找，再退出阅读；不抢输入法组词。
- “恢复出厂设置”统一称“恢复默认设置”，范围仍只偏好、不清全局历史与当前文档。
- `文件 → 导出…`／`⇧⌘E` 弹出包含格式、排版参数、文件名与输出位置的系统保存面板。支持 PDF 与结构化可编辑 DOCX，全部本地离线，不要求 Word 或外部转换工具。以当前正文的独立快照导出，不改正文、模式、历史、脏状态或源文件。
- 默认 A4纵向白底、正文12磅；普通段落首行缩进默认2字符，可关闭或调0–10字符；行距继承当前呈现模式〔排版编辑／源码／阅读〕的实际正文行高，可为本次输出调整0.5–5倍字号。中英文字体默认采用首选项的本机字体，允许单次导出调整。标题／列表／代码／表格不套首行缩进，代码等宽。Word保留标题、段落、列表、表格、样式与代码为可编辑结构，图片和离线 Mermaid 嵌入图片。应用主题、内容缩放、目录、行号和界面控件不导出；网络资源限制不放宽。
- 输出默认同 Markdown 目录，未保存文档需选择位置，覆盖已有文件由系统确认；禁止以导出覆盖 Markdown 源文件。导出中的文档不允许关闭至输出完成；失败保留编辑，明确提示。不支持的或不可用资源不得静默伪造成功。

## 11. 诊断、外观与隐私增强

- 编辑中的 `<!-- … -->` 单行、多行与行内注释使用等宽、灰绿色弱化样式，不作为普通正文排版；阅读、PDF／DOCX导出及打印忽略注释，不留注释占位段落，原文保留。注释内容不解析成 Markdown 或 HTML；行内代码、围栏／缩进代码示例及非Markdown原文中的相似字符串正常保留，其他原始HTML的非执行策略不变。
- 持久错误日志覆盖可捕获的启动、打开、保存、文件夹、图片、桥接、导出、渲染与 WebKit 异常。日志只存本机时间、固定事件、严重级别、版本、随机会话 ID、错误类型、白名单错误域和错误码，不存正文、路径、URL、错误消息或凭证。日志轮转为最多5份、每份约2MiB，可在现有“缓存清理…”中删除，运行中清理后可继续记录。强制终止、系统崩溃等不能保证有最后一条日志，不提供正文恢复。
- 导出完成或失败后发送本地 macOS 通知，主动取消不算失败。用户确认首次实际导出后才申请通知权限；拒绝后不反复申请。权限／系统勿扰等可能抑制通知，应用内仍提供结果提示：成功约5秒自动消失，也可手动关闭；失败保留至关闭或后续操作。新提示替换旧提示后，旧计时器不得清除新提示。通知只显示结果与文件名，不注册远程推送、不上传数据。
- 文件树用目录、Markdown、文本、代码、图片、PDF、办公文档、压缩包、影音与未知文件图标区别类型；不改变原有可打开格式或文件权限。鼠标移入文件导航，所有已显示条目展示最近修改时间；离开约3秒隐藏，重新进入取消隐藏。时间遵循本地／UTC设置，未展开目录不递归预扫。
- 纸质与牛皮纸使用本地静态材质表现纸面，不只是背景色或均匀噪点：纸质参考旧实体书的非光滑纸面，能看出不均匀纸浆、残留纤维及轻微粗糙起伏；牛皮纸保留自然的纤维和压制纹理。纤维及局部色差应清晰可辨，同时保持整体色调和文字可读性。材质只在背景，不污染字形，不联网加载，不持续动画或运行逐帧滤镜。新增全局界面外观：跟随系统〔默认〕／浅色／深色；深色关闭纸纹，浅色恢复各模式已有纸张选择，原生窗口与编辑区保持一致。
- 无文档时的中央欢迎页、顶部和最近位置侧栏共用同一纸张背景。允许仅通过原生窗口背景将相同静态纸纹延伸至系统红黄绿按钮所在标题栏；不扩大WebView覆盖范围，不自绘系统按钮、不接管拖动／双击，不改变系统双击设置。原生背景方案不可靠时保留现有标题栏，深色与护眼继续不显示纸纹。
- “显示 → 专注模式”与首选项共用同一开关并显示勾选状态。专注作用于排版编辑和源码，不增加第二套正文。
- “编辑 → 删除整行”／`⇧⌘K` 删除源逻辑行，非视觉折行；“删除整段”／`⌥⇧⌘K` 删除当前语义段落。支持一次撤销，不使用系统剪贴板。整段操作保护代码块和表格结构，表格内两个动作只清空当前单元格；只在正文聚焦且可编辑时执行，不抢组词。
- 首选项分别保存编辑与阅读行距，实时作用于所有文档。以各呈现模式的旧包实际行高为紧凑基准1×〔排版编辑正文1.4倍字号，源码／阅读正文1.85倍，代码与表格沿用各自原基准〕；默认1.3×、宽松1.5×分别表示比原效果增大30%／50%，不是绝对字号倍率。自定义0.75–2.5×，默认选择1.3×。源码与排版共用编辑相对倍率。导出继承当前呈现模式的实际正文倍率〔默认排版编辑1.82，源码／阅读2.405倍字号〕，单次导出调整不反写全局偏好。不得仅根据旧CSS的1.85声明忽略CodeMirror实际覆盖值。
- 快捷键说明位于应用内容前层，首次及再次打开都从顶部开始，按文件／编辑／格式／显示／窗口与应用／阅读导航分类，不跨应用常驻置顶。帮助菜单增加离线使用文档，重点解释源码、专注、阅读的理念与用法。
- 编辑／阅读往返保持固定原生内容区域与窗口外框，不反复切换内容延伸样式；使用真实AppKit标题栏，Web内容始终位于其下方，目录按钮、标签不能与系统按钮重叠。标题栏拖动、双击及其系统设置由AppKit处理，不将标题栏双击硬编码成缩放，不与标签栏空白双击新建混用。`⌘W`优先关闭当前原生辅助窗口／取消当前系统面板或Web模态层，不关闭其背后的文档。
- 每次交付前进行全产品与依赖隐私检查：覆盖产品／构建代码、实际随包资源、锁定的直接／传递依赖及其真实打包引用。除用户配置S3后的限定图片传输外，任何应用或依赖的自动外部请求均禁止，不因“没有发送敏感数据”而放行。保留 CSP、非持久 WebKit、资源／导航拦截，并对可信依赖的 fetch／XHR／WebSocket／EventSource／Beacon／WebRTC／WebTransport／Worker 等接口禁用。只有用户主动打开外链才交给系统浏览器；主动打印、系统通知属于明确的系统交接，不等于应用后台外发。
- 隐私报告须记录范围、发现、处置与验证限制；静态扫描、已知路径测试及依赖完整性核对不能冒充形式化证明，也不能声称审查了系统闭源框架。实际系统通知呈现、原生菜单／输入法／窗口点击仍按独立验收边界报告。

## 12. 标题识别、章节链接与导航收起

- 阅读顶部文件名与复用的 Markdown 类型图标水平同排居中，不在原生标题栏留下孤立或重复的文件代理图标；保留标题点击返回编辑。阅读保留原生红黄绿按钮，系统全屏的按钮显隐仍由 macOS 管理，不改变窗口外框或标题栏归属。
- 排版编辑中的H1–H6在标题首字左侧的上角常显小号淡色级别角标，与标题首行位于同一行，预留独立空间；不遮挡正文、行号或选择，不写入Markdown、不进入撤销／复制／导出内容；多行标题只标一次。源码保留原始标记，阅读不显示角标。
- 编辑与阅读共用 H1–H6 字号级差；同字体与同内容缩放下对应级别大小一致，最低级别不小于正文。编辑／阅读的独立缩放和行距偏好仍保留。
- 主动打开本地 Markdown 链接时在应用内打开或激活并固定目标标签；带 `#章节` 的链接定位相应标题，支持中文百分号编码、重复标题的递增后缀与已打开文档。阅读保持阅读，排版／源码保持当前模式；不重载已打开文件、不丢编辑或历史。缺失章节明确提示，畸形链接不抛未处理异常；危险目标校验、图片权限与外部链接的系统交接不放宽。同文档章节链接也可在编辑／源码／阅读中定位。
- Mermaid 放大层在有剩余空间的轴上居中；溢出轴保留两端可达的滚动范围。适应窗口、独立缩放和拖动平移继续可用。
- 文件导航的类型图标与文件名首行对齐，最近修改时间位于名称下方；显示／隐藏时间时不改变行高或使图标漂移，保留原悬停延时与本地／UTC规则。
- 文件导航独立通过“文件”按钮及面板收起按钮展开／收起，采用目录的收起交互；目录与文件树仍可独立左右布局，收起不关闭文件夹或文档，不丢失展开分支。进入阅读临时隐藏文件导航，返回恢复原展开／收起状态。
- 标签关闭按钮继续保留右侧；关闭按钮左移的提议已取消。

## 13. 文档切换、帮助内容与通用客户端

- 超链接打开或激活另一文档时，正文使用约200ms的淡入及小幅横向移动，文件名与活动标签同步更新；带章节地址时先定位目标，再呈现新文档。同文档章节跳转继续平滑滚动。排版编辑、源码及阅读均适用，保留已打开文档的内容和历史，快速切换及后续输入可以取消旧动画；系统“减少动态效果”开启时直接切换。
- 应用内中英文帮助与使用说明使用中性、正面、准确的表达，按功能、操作和结果组织。采用大众熟悉且符合产品功能的术语；保留必要的使用条件和数据保护提示。过程决策、历史实现比较及测试信息放在工程或发行记录中。省去无意义的举例、反例、比喻、新造词和不合时宜的排比，按需使用对比说明。
- 从本批起默认交付一个 Universal 通用客户端，同时编译 arm64（Apple Silicon）和 x86_64（Intel），共享一份 Web 资源。分别核对编译结果及合并、签名和解压后的两种架构，保持现有离线、权限、体积及资源要求。
- Apple Silicon 本机可交叉编译 Intel 版本，使用已有 Rosetta 补做部分转译运行检查。构建与转译结果分别记录，Intel 真机及其他 macOS 版本的兼容性按实际验证情况说明；编译部署目标继续不作为最低系统兼容承诺。

## 14. 章节复制、快捷插入与图片存储

- 文档目录右键提供复制、剪切、删除，范围为该标题起至下一同级或更高级标题之前，包含全部子章节。阅读仅复制；剪切须在完整副本写入剪贴板成功后才删除，剪切／删除均为一次可撤销事务。
- 正文⌘C有文字或单元格选区时复制选区，没有选区时复制整个段落，不改变光标及选区；排版单元格的范围以 §15 为准。不会将⌘V改为复制。Markdown段落副本同时携带Markdown与HTML／RTF等富文本表示，支持回贴Markfine及粘贴到Word等应用。自有结构化副本中本地图片以自包含原始数据迁移至目标文档资源目录，S3图片保留链接；引用定义只带选中内容实际使用的项目。复制不包括Hx角标、行号、专注弱化或其他界面内容。
- 异步复制在生成快照前向原生取得票据，绑定会话、文档、内部代次及剪贴板changeCount。后续复制或其他应用／原生输入控件更新剪贴板时，旧操作不可覆盖新内容，旧剪切也不删除源文；取消／失败／过期释放状态。
- 排版编辑普通空行行首输入半角/，显示跟随光标的格式图标清单；上下选择、Return确认、Esc关闭，选择替换/并一次可撤销。源码、代码块、表格、注释及输入法组词期间沿用原有输入行为。
- 通过格式命令或 `/` 在有序列表之后插入列表时，仅跨空行自动接续前一列表编号；已有普通正文、标题或其他语义块分隔时从1开始，手动继续编号使用序号右键菜单。
- 表格支持跨单元格拖动及Shift点击矩形选择，保留单元格内文字选择。复制选区携带表格结构与对齐；没有选中表头时，正文中的Markdown表格使用空表头保留全部数据行。右键另有“复制表格源码”，复制整表原始Markdown。
- 图片显示比例均相对于原始尺寸。默认自动计算：小图按原图显示，大图按当前可见正文可用宽度等比缩小。所有手动预设25%、50%、75%、100%、150%、200%和自定义值都受正文宽度上限约束；超限项禁用。窗口、侧栏、行号或内容缩放变化时只约束呈现，不自动改写文件。
- 自动适配图片保留普通Markdown图片写法，手动宽度使用Obsidian约定 `![图片|600](image.png)`，高度等比；表格中的竖线正确转义。恢复自动移除宽度后缀。复制／阅读／导出使用保存的尺寸，分页输出按页面范围约束。原图不重新缩放或压缩。
- 图片粘贴默认本地；原生首选项可配置S3兼容存储的HTTPS服务地址、区域、存储桶、图片目录、地址形式及读取方式（凭据／公开链接和可选访问根地址）。读取方式与服务实际权限一致，应用不自动改写存储桶权限。粘贴位置只影响后续新图片，已配置服务中的文档图片可按授权继续读取。
- S3凭据及完整服务绑定共同存系统钥匙串私密值；UserDefaults只保留非秘密配置与不透明条目ID，不同步凭据。网页不获得凭据；所有S3请求由原生使用HTTPS及SigV4处理，只重建并请求配置服务内的图片路径，公开图片请求不携带S3认证，拒绝重定向及其他认证挑战，保留系统TLS验证。保存配置只本地校验，不后台试连；本地选择、重置、删除或较新的配置操作可使尚未执行的旧保存票据失效。
- S3上传中有取消入口，失败保留合成／实际待处理图片并提供重试、改为本地或取消；回执校验原文档、请求及版本。用户改配置后可重试失败任务，运行中的旧上传不会使用新配置混合认证。撤销／取消不自动删除远端对象。
- S3图片读取按canonical对象键复用同一文档的暂存文件，串行处理传输、验证及落盘；队列最多32个请求，单响应最多64MiB。管理暂存限制为单文档256MiB／会话512MiB，清理失败继续计入预算；正式附件不自动清理。普通远程资源和Web通用联网入口保持禁用。
- 首选项分为通用、编辑与导航、外观、图片与存储。去除原有整段行距历史说明；必要注释放在对应控件旁或控件提示中，符合帮助写作要求。恢复默认将粘贴位置恢复本地，S3凭据由独立删除入口管理。

## 15. 通用文本、快捷输入与复制反馈

- `/` 格式清单每个选项右侧以较淡颜色显示实际快捷键；普通空行行首显示淡色斜体“输出/选择常用组件并快速插入”，颜色比专注模式下的非活动正文更淡，并适配各主题及深色外观。提示不写入正文、复制、导出或撤销历史，源码、代码块、表格、注释、只读及组词时不显示。
- 默认补齐中英文括号、引号、书名号等成对标点；可包围选区，已有右符号时跳过，空符号对可一起删除。正常组词、粘贴和英文缩写撇号不额外补齐，插入和删除可撤销。
- 不按扩展名白名单限制纯文本编辑；文件须通过普通文件、实际内容及无损Unicode解码校验。支持UTF-8（可带BOM）、带BOM的UTF-16/32大小端；无法可靠识别的编码不猜测、不替换损坏字节。打开上限16MiB；保存也有16MiB的原编码字节上限，超限保留当前编辑，不截断原文件。
- Markdown维持排版、源码及阅读；其他文本以等宽原文编辑和只读原文预览。常见代码按现有离线语言集高亮，未知语言或超过现有高亮预算时显示原文。不把文本当Markdown排版，不再对可编辑文本显示默认程序按钮。
- HTML、SVG、脚本、配置等文件均作为数据；不预览网页、不运行程序、不加载其引用的图片、字体、脚本、外部样式或网络资源。普通文本不登记图片授权，粘贴及复制只使用纯文本，不创建附件或触发S3；导出也保留原文。
- 继续复用同一标签正文、选区、历史、保存及未保存保护。保存保留原编码、BOM、换行与文件权限；已有外部变更、失败安全写入及符号链接／文件身份保护保留。文件树原条目在描述符校验前不解引用符号链接；新读取同时校验选定inode。应用声明文本编辑类型但不自动更改系统默认关联。
- 最近记录增加打开来源。仅通过文件夹导航打开的文件默认隐藏，可在“打开最近”、空白页最近记录及首选项中开启“显示从文件夹导航打开的文件”，开关按当前用户记忆并同步影响菜单及空白页。保留隐藏记录，不以文件所在目录推断来源；旧记录继续可见。通过菜单或Finder直接打开的文件保持可见，后续文件树点击不使它消失。显示最多20条，隐藏来源单独有界保存，不挤掉20条直接打开记录；清空操作同时清除两类记录。
- 右键及Control单击打开菜单时保留原有光标、文字及单元格选区；命令范围独立按右键对象确定。菜单聚焦不得滚动正文，不影响原有左键选择、拖动及输入法。
- 无选区复制段落直接读取范围，不先选中整段、不触发光标居中。排版单元格有文字选区时复制所选文字，无选区时复制当前单元格可见文字，不附加整表结构；源码模式无选区仍复制整表。矩形选区及明确的“复制表格源码”入口保留。
- 剪贴板实际写入成功后显示“已复制”，约1.2秒自动消失；复制进度与成功提示均悬浮且不占正文排版空间，不移动光标、焦点或滚动位置。失败不显示成功，仍保留错误与剪切失败保护。
- 无选区复制段落或单元格成功后，对已复制文字的当前可见部分显示半透明高亮，约0.1秒出现、0.6秒停留、0.3秒淡出，不创建真实选区。新复制、输入、滚动、调窗、切页或模式切换取消旧高亮；遵循系统减少动态效果设置。不改变正文、撤销历史或复制内容。
