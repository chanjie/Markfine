# Markfine 产品需求

## 1. 目标与范围

面向 macOS Apple Silicon 的轻量 Markdown 客户端，优先可靠的本地文件编辑、块级实时排版和高效键盘操作。Markdown 源文件是唯一持久化正文，不引入专有文档格式。

首版必须在同一应用中包含：真实文档闭环、多标签、块级 Markdown、查找替换与常用快捷键、纯文本/本地图片粘贴及首次保存迁移、离线 Mermaid。不能用单文档或仅文字版本替代。

- 当前使用对象为内部少量用户，不通过 Mac App Store 分发。
- 正式运行验收环境为 macOS 26.7.2 / Apple Silicon，性能基准为 Apple M5 / 32 GiB；其他系统未承诺兼容。工程部署目标不等同于最低支持版本。
- Typora 仅作为体验参考，独立设计实现，不复制其代码或资源。

## 2. 文档与多标签

- 新建、打开 UTF-8 Markdown 文件；同窗口多标签，正文、选区、历史、滚动位置与脏状态相互独立。
- 同一文件只保留一个标签；重复打开激活已有标签，不重载编辑内容。同名不同文件应可区分，不能以标题关联读写。
- 显式 `⌘S` 保存。新文档首次保存选择名称和位置，已有文件保存回当前路径；不提供另存为或应用内重命名。
- 首次保存覆盖已有文件须经系统替换确认，目标已在其他标签打开时拒绝覆盖。
- 保存前检查文件身份、内容和元数据；外部改写、删除、移走或替换时停止保存并保留编辑，不自动覆盖、重载或合并。
- 写入失败保护旧文件及当前编辑；提交后结果无法确认必须区别于“未写入”，不得自动重试或关闭。
- 保存期间允许继续输入。回执仅确认对应文档/请求/版本的快照，不重载正文、选区或历史；后续编辑保持未保存，撤销回保存内容恢复干净状态。
- 同文档保存串行，重复显式保存可合并排队，不让旧快照后写覆盖新快照。
- 关闭标签、窗口、退出都处理未保存修改，提供保存、放弃或取消。取消/失败/保存后新修改应中止关闭。最终批准与真正关闭之间不得丢失新输入。
- 不做自动保存或异常退出后的未保存正文恢复。

## 3. 编辑与语法

- 当前块显示可编辑 Markdown，其余块呈现排版结果；切换不丢文本、选区或撤销历史，非活动块实时更新。
- 正常中文组词，不抢占输入法处理中的 Return、Esc、方向键；组词期间不强制切换标签或执行业务命令。
- 核心语法基线为 CommonMark 0.31.2；GFM 参考 0.29-gfm，仅明确加入表格、任务列表、删除线、自动链接。
- 原始 HTML 和脚本仅显示源码。安全策略导致的语法差异单独说明，不宣称完整原始 HTML 或 GitHub 网站行为兼容。
- 不支持/渲染失败保留原文并提示，但不得把全部降级视为已声明语法正确渲染。
- 当前文档查找与替换可通过键盘完成，替换可撤销；格式动作只作用于聚焦的正文，剪贴板/撤销跟随实际输入控件，菜单和编辑器不得执行两次。
- 键位基线见 [SHORTCUTS.md](SHORTCUTS.md)，不提供应用内自定义快捷键。

## 4. 剪贴板、图片和资源生命周期

- 图片数据选择顺序为可用 PNG → JPEG → TIFF。PNG/JPEG 原字节保存，TIFF 转 PNG，不主动缩放或有损再压缩，扩展名匹配实际格式。
- 没有可用图片则按纯文本粘贴；不解析 HTML/RTF 提取图片、不下载 URL、不承诺格式化文本、动画保留或 SVG/PDF 矢量转换。
- 无受支持内容提示不支持，不插坏链接或改变正文；已有资源文件不重新编码。
- 已保存文档粘贴时立即写入同级 `<文档名>.assets/` 后插入相对引用，资源写入不等于保存正文。
- 新文档图片先写自身暂存、可预览，首次保存迁移为 `.assets` 相对路径。迁移不破坏当前编辑、选区、历史或后续修改，也不能全局替换普通文字/代码中的相似字符串。
- 文件名 `image-<UUID>.<实际扩展名>`，每次新建，不沿用剪贴板名称、不按内容去重；重名换 UUID，不覆盖、改名或删除原资源。资源目录被普通文件占用或不可写时报错，保留暂存。
- 图片处理异步，显示可取消提示；仅锁目标文档的编辑/保存/关闭/再次粘贴，允许滚动及切换、编辑其他标签。同一时刻最多一个图片任务，退出前等待或取消。
- 任务绑定文档、插入位置、版本和任务 ID。成功一次可撤销插入；失败/取消不改正文，迟到回执无效。临时提示不进入 Markdown 或历史。
- 存活标签的暂存不因删除引用、撤销或保存成功而立即清理。只有真正关闭标签后清理自身暂存；取消关闭/保存失败继续保留。
- 正常退出确认后清理本会话；异常退出后仅清理可证实已失效的会话，存活或无法确认的保留。清理限应用管理目录，失败不阻断编辑。
- 正式 `.assets` 永不自动清理，即便已无引用。保存后重新打开或 Markdown 与 `.assets` 一起移动，图片应仍有效。

## 5. 离线图表与内容安全

- 固定标准版 `mermaid@12.3.0`，首版保证流程、时序、类、状态、ER、甘特六类；不自动跟随最新版或改用 tiny 分发。
- Mermaid 运行时本地打包，不依赖 CDN/外部服务。严格安全模式，禁止脚本回调、安全配置覆盖和远程资源加载；错误保留源码与提示，不阻断编辑。
- 不自动联网加载文档的图片、脚本、字体；远程图片显示占位和原链接，不改写源文。用户主动点击 HTTP(S) 外链才交系统浏览器，编辑器不得导航走应用页面或执行危险协议。
- 本地图片仅当前文档目录/子目录和该文档自身暂存；未保存文档仅自身暂存。路径规范化、符号链接及竞态不能绕过权限，不扩大到整个工作区或其他标签。
- 文档内容不拥有原生能力。桥接需校验来源、frame、独立 content world、会话、能力、文档、请求和版本；只能调用固定应用命令，不接收任意文件路径或执行系统命令。

## 6. 性能目标

下列为验收目标，不是当前全部已实测通过的结果：

| 指标 | 目标与口径 |
| --- | --- |
| 20 KiB UTF-8 文档启动 | 完全退出后打开到首屏可见且可输入 ≤1 秒，保留系统文件缓存 |
| 1 MiB 综合文档打开 | 到首屏可见、可输入且预览可用 ≤3 秒 |
| 输入到显示 | P95 ≤100 ms |
| 离开活动块到该块排版出现 | P95 ≤200 ms，不计停留编辑时间 |
| 滚动帧 | P95 ≤33 ms，无 >300 ms 明显卡顿 |
| 1 MiB 稳态内存 | 完整浏览并稳定后采样 60 秒，每次合计主程序及确认归属的 WebKit RSS，最大值 ≤300 MB |
| Release `.app` 体积 | ≤50 MB，不用 ZIP 大小代替 |

20 KiB 启动文档不含图片/图表；1 MiB 样例包含常用语法、六类小图和四张本地 PNG/JPEG，附件字节另计。两档启动各保留 10 轮、输入和预览各至少 100 次、滚动 3 轮每轮至少 30 秒。Gatekeeper 人工批准不计启动性能，启动/图片转换峰值另记，不能以均值代替稳态最大值。

常规小文档还需关注空闲及持续编辑的 CPU、内存、热压力，与同机同文档参考体验比较；数值/热判据尚未确认，不凭空作达标承诺。

## 7. 分发与非目标

SwiftPM Release arm64 `.app`，运行资源全部随包；当前 ad-hoc 本地签名、ZIP/SHA-256 和版本说明，不要求使用者安装开发工具。无 Developer ID/公证，不关闭系统安全策略，不自动安装或改默认文件关联。更新前完成图片任务、保存并退出，只替换 `.app`，保留旧包便于手动回退，不改用户文档或 `.assets`。

首版不含：其他平台、账号/应用内同步、另存为/重命名、自动保存/恢复、HTML/RTF 格式化粘贴、Word/PDF 导出、S3、插件/AI、自定义快捷键、数学/脚注等额外语法、安装器和自动更新。
